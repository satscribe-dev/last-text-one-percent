A program that writes the funniest final text message a dying phone sends at
one percent battery — in the phone's own voice, under 200 characters.

Run it with Node 22:

```sh
node main.ts
```

It writes one text to `/output/entry.txt`, deterministically: every run
produces the same bytes.

Entry: a phone saying goodbye after watching its owner type "i love you"
and delete it 14 times.
